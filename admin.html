⚙️ Setup Guide — Firebase + Cloudinary

This admin panel uses Firebase Firestore for data (events, members, gallery info) and Cloudinary for hosting images/videos. Both have generous free tiers — no credit card needed.

Step 1 — Create a Firebase Project (Spark / Free plan)

1Go to console.firebase.google.com and sign in with your Google account.
2Click "Add project" → name it india-i-agder → disable Google Analytics → Create.
3In the left sidebar, click Firestore Database → "Create database" → choose "Start in test mode" → pick region europe-west3 (Frankfurt) → Done.
4You can skip Firebase Storage — we're using Cloudinary instead, so you stay on the free Spark plan.

Step 2 — Get your Firebase config

1Go to Project Settings (gear icon) → scroll to "Your apps" → click "</> Web" → register app → copy the config.
2Open admin.html in any text editor and replace the values in FIREBASE_CONFIG.
const FIREBASE_CONFIG = { apiKey: "AIzaSy...", authDomain: "india-i-agder.firebaseapp.com", projectId: "india-i-agder", storageBucket: "india-i-agder.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc123" };

Step 3 — Create a Cloudinary account (free)

1Sign up at cloudinary.com — free plan gives 25 GB storage + 25 GB bandwidth/month, no credit card needed.
2On the dashboard, copy your Cloud Name (shown at the top).
3Click the gear icon (Settings) → Upload tab → scroll to Upload presets → "Add upload preset".
4Set Signing Mode = Unsigned, give it a name (e.g. iia_uploads), save.

Step 4 — Paste Cloudinary keys into admin.html

1In admin.html, find CLOUDINARY_CLOUD_NAME and CLOUDINARY_UPLOAD_PRESET.
2Replace the placeholders with your values:
const CLOUDINARY_CLOUD_NAME = "your-cloud-name"; const CLOUDINARY_UPLOAD_PRESET = "iia_uploads";
3Do the same in fixed_carousel.html if it also uploads media.

Step 5 — Change the Admin Password

1In admin.html, find ADMIN_PASSWORD.
2Change it to a strong password of your choice.
3Also change ADMIN_USERNAME from admin to whatever you prefer.
💡 Note on deletes: When you delete a slide or gallery item from this admin panel, the record is removed from Firestore and the item no longer shows on your site. The actual file stays in your Cloudinary account (because unsigned client deletes aren't allowed for security). You can periodically clean up unused files from the Cloudinary dashboard if you like.
