# Restaurant images

Drop a photo for each restaurant in this folder using the filenames below.
The app reads them automatically — no code changes needed.

Suggested size: **800–1200 px wide**, landscape orientation, JPG or WEBP for
small file size. Square also works (the card crops to fit).

| Restaurant         | Filename                  |
| ------------------ | ------------------------- |
| Marco Polo         | `marco-polo.jpg`          |
| Hong Kong          | `hong-kong.jpg`           |
| Happy Time         | `happy-time.jpg`          |
| Mønsj              | `monsj.jpg`               |
| Streetfood Arendal | `streetfood.jpg`          |
| Madam Reiersen     | `madam-reiersen.jpg`      |
| Café Victor        | `cafe-victor.jpg`         |

If a file is missing, the app silently falls back to the coloured banner
with an emoji — nothing breaks.

If you prefer `.png` or `.webp`, change the `image:` field in `data.js`
for that restaurant to match (e.g. `images/monsj.webp`).
